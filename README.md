# InventorGostSpec

Аддин для Autodesk Inventor 2025, формирующий спецификацию по ГОСТ 2.106-2019.

Возможности:

- назначение компонентам категорий (разделов спецификации) через iProperties, в том числе автоматически для стандартных изделий из Content Center;
- формирование спецификации по первому уровню сборки со строгой сортировкой по ГОСТ;
- ручное редактирование порядка, разделов, примечаний и любых колонок;
- обновление только по команде пользователя, с сохранением ручных правок;
- резерв номеров позиций между разделами;
- запись позиций в BOM Inventor;
- экспорт в Excel для ручной правки и вывод в PDF по ГОСТ 2.106 (формы 1 и 1а, основные надписи 2 и 2а).

Статус: в разработке. Подробные требования — в [docs/REQUIREMENTS.md](docs/REQUIREMENTS.md).

## Требования

- Autodesk Inventor 2025
- .NET 8 SDK
- Visual Studio 2022

## Сборка и установка

1. Откройте `InventorGostSpec.sln` в Visual Studio 2022.
2. Закройте Inventor и соберите решение в конфигурации **Debug**. Аддин автоматически копируется в
   `%APPDATA%\Autodesk\ApplicationPlugins\InventorGostSpec\`.
3. Запустите Inventor. В сборке на вкладке **«Сборка»** появится панель **«Спецификация ГОСТ»**: большие кнопки «Спецификация» и «Позиции в BOM», маленькие — «Раздел», «Авторазделы», «Имя из файла». В детали — кнопка «Раздел» на вкладке **«Управление»**.

Если Inventor установлен не в `C:\Program Files\Autodesk\Inventor 2025\`, укажите путь:
`dotnet build -p:InventorInstallDir="D:\Autodesk\Inventor 2025\"`.
Для Release скопируйте содержимое `src\InventorGostSpec.AddIn\bin\Release\net8.0-windows\` в папку плагинов вручную.
Утилита PDF собирается вместе с аддином и лежит в его папке `PdfTool\`.

Тесты запускаются без Inventor:
`dotnet test tests/InventorGostSpec.Core.Tests`, `dotnet test tests/InventorGostSpec.UI.Tests`,
`dotnet test tests/InventorGostSpec.Excel.Tests`, `dotnet test tests/InventorGostSpec.Pdf.Tests`.

## Команды

| Кнопка | Что делает |
|---|---|
| Раздел | Назначает раздел и поля сортировки выбранным компонентам (или открытой детали). При выборе нескольких компонентов меняются только изменённые поля. |
| Авторазделы | Компонентам первого уровня без раздела: Content Center → «Стандартные изделия» (и поля сортировки из наименования), сборки → «Сборочные единицы», детали → «Детали», виртуальные → «Прочие изделия». Если рядом с деталью лежит чертёж с тем же именем, заполняется формат. Компоненты с заданным разделом пропускаются. |
| Имя из файла | Записывает в наименование (Description) стандартных изделий сборки, включая подсборки, имя их файла — как есть, без перестановок. Перед записью — окно «Было / Станет» с предупреждением: можно выбрать изделия и поправить значение вручную. Если наименование уже совпадает с именем файла, строка помечается и пропускается. Галочка «Очистить поля сортировки» (включена по умолчанию) удаляет у переименованных изделий `SPEC_SortName`, `SPEC_StandardNumber`, `SPEC_Parameters`, заполненные по старому наименованию. Со спецификацией не связана. |
| Спецификация | Открывает окно спецификации. При первом открытии спецификация формируется по составу сборки. |
| Позиции в BOM | Записывает номера позиций из сохранённой спецификации в Item Number спецификации Inventor. |

### Окно спецификации

Окно работает с копией спецификации: в сборку она записывается кнопкой «Сохранить» (Ctrl+S), после чего
нужно сохранить и саму сборку. Состав из сборки перечитывается только кнопкой «Обновить из сборки».

Команды сгруппированы на панели: **Сборка** (обновить, следующее изменение, принять), **Строки** (изделие, текст,
удалить, вверх/вниз), **Структура** (раздел, группа), **Позиции** (по ГОСТ, перенумеровать, резерв),
**Вывод** (Excel, настройки PDF, PDF, позиции в BOM). Справа — поиск по обозначению, наименованию, примечанию и позиции.

| Клавиши | Действие |
|---|---|
| F5 | Обновить из сборки |
| F3 | Следующее изменение |
| Alt+Enter | Свойства компонента |
| Ctrl+S | Сохранить |
| Ctrl+F / Esc | Поиск / очистить поиск |
| Insert | Добавить изделие |
| Ctrl+T | Добавить текст |
| Delete | Удалить строку |
| Ctrl+↑ / Ctrl+↓ | Переместить строку |
| F2, двойной щелчок | Редактировать ячейку |
| Ctrl+щелчок / Shift+щелчок | Выбрать несколько строк |

Размер и положение окна запоминаются.

- Таблица с колонками ГОСТ: Формат, Зона, Поз., Обозначение, Наименование, Кол., Примечание (и единица измерения).
  Заголовки разделов — в графе «Наименование», по центру, подчёркнуты.
- Несколько строк выбираются Ctrl+щелчок (по одной) и Shift+щелчок (диапазоном). «Перенести в раздел»,
  «Перенести в группу», «Свойства компонента…», «Удалить строку» и «Вернуть значение из компонента» применяются
  ко всем выбранным строкам; порядок строк сохраняется, выбор — тоже.
- Группа сортировки (колонка «Гр.», контекстное меню «Группа сортировки») — число 0, 1, 2…, по умолчанию у всех
  строк 0: внутри раздела строки с меньшим числом идут выше, внутри группы — порядок по ГОСТ. Хранится только
  в этой спецификации, в компоненты не записывается. Применяется кнопкой «По ГОСТ».
- «Примечание из детали» (контекстное меню) — вставляет в графу «Примечание» выбранных строк примечание из свойств
  детали: пользовательское свойство «Примечание», а если его нет — «Комментарии» (вкладка «Сводка»). Имя свойства
  задаётся в `%APPDATA%\InventorGostSpec\settings.json` (`notePropertyName`). Уже заполненное примечание заменяется
  только после подтверждения.
- «Свойства компонента…» (контекстное меню, кнопка «Свойства», Alt+Enter) — раздел, формат, единица и поля
  сортировки компонента. Записываются сразу в iProperties файла (действуют во всех сборках), строка тут же
  обновляется: при смене раздела переходит в новый раздел и получает номер из его резерва.
- Любую ячейку можно изменить (двойной щелчок или F2). У строк компонентов это меняет значение только в этой
  спецификации, не в детали; такие ячейки выделены синим курсивом, в подсказке — значение компонента.
  «Вернуть значение из компонента» — в контекстном меню.
- Подсветка после обновления: зелёный — новый компонент, жёлтый — изменился (в подсказке «Было: …»),
  красный — компонента нет в сборке. «Принять изменения» снимает подсветку и удаляет такие строки.
- Порядок строк: перетаскивание за «⋮⋮» или Ctrl+↑/↓ внутри раздела. Номера позиций раздела следуют за порядком.
  «Перенести в раздел» — контекстное меню.
- «+ Изделие» — строка без модели (номер позиции берётся из резерва), «+ Текст» — текстовая строка.
- «Раздел…» — новый раздел для этой спецификации или для общего справочника.
- «Группа…» — группа «Изделия, устанавливаемые по …» (например, по электромонтажному чертежу МЭ). Записывается после
  основной части со своими разделами (сборочные единицы, детали, стандартные, прочие изделия, материалы), отсортированными
  по ГОСТ; номера позиций продолжаются подряд после основной части. Строки переносятся командой
  «Перенести в группу» в контекстном меню; принадлежность к группе хранится в спецификации сборки, а не в детали.
  Заголовок группы редактируется прямо в таблице; «Удалить группу» возвращает её строки в основную часть.
- «Резерв…» — резерв номеров и округление начала раздела, отдельно для основной части и каждой группы;
  «Показывать резерв» — пустые строки резервных позиций.
- «Сбросить порядок» — сортировка по ГОСТ и перенумерация; «Перенумеровать» — нумерация в текущем порядке.

### Экспорт в Excel

Кнопка «Excel» (группа «Вывод») выгружает текущее состояние окна в `.xlsx` — для ручной правки и последующего
вывода в PDF по ГОСТ. Пример: [docs/Пример спецификации.xlsx](docs/Пример%20спецификации.xlsx).

- Лист «Спецификация»: колонки ГОСТ (Формат, Зона, Поз., Обозначение, Наименование, Кол., Примечание),
  «Ед. изм.» и «Тип строки» — Группа / Раздел / Изделие / Текст / Резерв / Пустая / Новый лист (выбирается из
  списка). По типу утилита PDF оформляет строки; строки можно свободно править, добавлять и удалять.
  - «Пустая» — пустая строка, добавленная вручную (например, чтобы запись, не помещающаяся на лист, целиком
    перешла на следующий); «Текст» без текста — тоже пустая строка, её можно добавить кнопкой «+ Текст» в окне.
  - «Новый лист» — следующие строки начинаются с нового листа PDF.
  - Колонка «Лист PDF» и жирные линии — разметка листов: номер листа у первой его строки, линия под последней.
    Раскладка та же, что в PDF (с теми же настройками шрифта). После ручной правки разметку обновляет кнопка
    «Разметить листы в Excel» в утилите PDF.
- Лист «Основная надпись»: обозначение (без «СБ»), наименование, организация, литера, подписи — заполняется
  из iProperties сборки (Part Number, Description, Designer, Checked By, Engr Approved By, Company), остальное вручную.
  «Шрифт наименования, мм» — высота шрифта наименования в основной надписи для этого документа (пусто — из настроек
  утилиты PDF); при повторной выгрузке и при выводе PDF из Inventor берётся из прежнего файла, как и лист «Изменения».
- Лист «Изменения» — графы изменений основной надписи для внесения изменений в КД (ГОСТ 2.503): «Изм.»
  (номер изменения), «Кол. уч.», «Лист», «№ докум.» (обозначение извещения), «Подп.», «Дата». Одна строка — одна
  запись, по порядку внесения; ячейки текстовые («1-3» и «05.25» не превращаются в даты). Заполняется вручную;
  при повторной выгрузке в тот же файл записи переносятся из него (файл должен быть закрыт в Excel).
- Лист «Как заполнять» — памятка. Формат файла описан в `src/InventorGostSpec.Excel/ExcelFormat.cs`.

Резервные строки выгружаются, если включено «Показывать резерв». Изменения в Excel в сборку не возвращаются.

### PDF по ГОСТ

Утилита `InventorGostSpec.PdfTool.exe` строит PDF из файла Excel в формате выше. Это отдельная программа: аддин
связан с ней только форматом файла и командной строкой.

- **Из Inventor** — кнопка «PDF» (группа «Вывод»): текущее состояние окна выгружается во временный Excel, утилита
  строит PDF (по умолчанию «‹обозначение› Спецификация.pdf» в папке сборки). Таблица изменений берётся с листа
  «Изменения» файла «‹обозначение› Спецификация.xlsx» рядом со сборкой, если он есть.
- **Настройки PDF** — кнопка с шестерёнкой рядом с «PDF» в окне спецификации открывает окно утилиты (шрифт, размеры
  шрифтов, сужение текста); если рядом со сборкой есть файл Excel спецификации, он подставляется в окно.
- **Без Inventor** — запустите `PdfTool\InventorGostSpec.PdfTool.exe` из папки аддина (или перетащите на него файл Excel):
  в окне выберите поправленный вручную Excel, файл PDF и шрифт.
- **Командная строка:** `InventorGostSpec.PdfTool.exe файл.xlsx --output файл.pdf [--font "GOST type B"] [--open]`.
  Код возврата 0 — успех, иначе текст ошибки в stderr. `файл.xlsx --mark-sheets` — разметить листы в Excel.

Что выводится:

- первый лист — форма 1 ГОСТ 2.106 (29 строк) с основной надписью по форме 2 ГОСТ 2.104: обозначение, наименование,
  подписи, литера, лист / листов, организация; последующие — форма 1а (32 строки) с надписью 2а;
- графы на поле подшивки (Инв. № подл., Подп. и дата, Взам. инв. №, Инв. № дубл.; на первом листе — Перв. примен.
  и Справ. №), «Копировал» и «Формат А4»;
- заголовки разделов и групп «Изделия, устанавливаемые по …» — по центру графы «Наименование», подчёркнуты (каждая строка), со свободной строкой выше и ниже; заголовок
  не остаётся внизу листа без строк раздела, многострочная запись не разрывается между листами;
- размеры шрифтов (высота прописных букв, ГОСТ 2.304) задаются в окне утилиты PDF, кнопка «По умолчанию»
  возвращает значения как в бланке спецификации КОМПАС-3D:

  | Что | По умолчанию, мм |
  |---|---|
  | Строки таблицы: изделия, заголовки разделов и групп, текст, формат (сжат по ширине графы) | 5 |
  | Заголовки граф «Обозначение», «Наименование», «Примечание» | 5 |
  | Вертикальные заголовки «Формат», «Зона», «Поз.», «Кол.» | 3,5 |
  | Обозначение документа | 7 |
  | Наименование изделия (для документа можно задать своё в Excel — «Шрифт наименования, мм») | 5 |
  | Организация (одной строкой, сжатой по ширине) | 10 |
  | Надписи и данные основной надписи: «Изм.», «Разраб.», фамилии, даты, изменения, литера, листы | 3,5 |
  | Графы на поле подшивки, «Копировал», «Формат А4» | 3,5 |

  Высота берётся по контуру буквы «Н», а не из метрик шрифта (у некоторых шрифтов они неверны); строки текста
  в одной графе — через 1,2 высоты букв;
- допустимое сужение текста (там же, по умолчанию 80 %): текст, который чуть-чуть не помещается в графу, сужается
  по ширине (высота букв не меняется) не больше чем до этой доли; если и так не помещается — переносится по словам
  («ГОСТ 7798-70», «ГОСТ Р ИСО 15973-2005» не разрываются). 100 % — не сужать, сразу переносить; 0 — автоматически
  не переносить вовсе (только по Alt+Enter), сужать сколько нужно;
- ручной перенос: Alt+Enter внутри ячейки Excel — в PDF строка переносится в этом месте (графы «Обозначение»,
  «Наименование», «Примечание», а в основной надписи — наименование);
- пустые строки и разрыв листа задаются в Excel типами «Пустая» и «Новый лист»;
- промежуток между разделами — одна свободная строка и ещё по пустой строке на каждую резервную позицию (номер
  позиции не печатается); строки «Пустая» из Excel добавляются так же;
- количество — вместе с единицей измерения («2,5 м»);
- изменения: на первом листе — все записи, на остальных — записи, у которых в графе «Лист» указан этот лист
  («2», «1-3», «1, 4»); в надписи две строки изменений — выводятся две последние записи.

**Шрифт.** По умолчанию — «Gost merged», он поставляется с утилитой (`PdfTool\Fonts\gost_merged.ttf`, исходник —
`src/InventorGostSpec.Pdf/Fonts`). Если файла нет — первый установленный шрифт ГОСТ 2.304 («GOST type B»,
«GOST type A», ISOCPEUR, OpenGost), иначе Arial. Текст всегда наклонный, как в КОМПАС-3D (наклон около 20°, шрифт в файле может быть прямым).
Шрифт, размеры шрифтов и сужение из окна утилиты сохраняются в
`%APPDATA%\InventorGostSpec\pdf.json` и действуют также при выводе PDF и разметке листов из Inventor.
Можно указать путь к файлу `.ttf`.
Подходят только шрифты TrueType (`.ttf`).

Состав берётся из структурированной спецификации Inventor (BOM): справочные компоненты исключаются,
вместо фантомных попадают их дочерние компоненты. Сборочный чертёж (`.idw`/`.dwg` с тем же именем,
что и сборка) автоматически попадает в раздел «Документация» с кодом «СБ».

Журнал ошибок: `%APPDATA%\InventorGostSpec\log.txt`.

## iProperties компонентов

Обозначение и наименование берутся из стандартных `Part Number` и `Description`. У сборок код «СБ» в конце обозначения
(«АБВГ.301234.001СБ», нужен для сборочных чертежей) в спецификацию не переносится — файлы при этом не меняются.
У сборочных единиц и комплексов без `SPEC_Format` в графе «Формат» ставится «А4» — формат их спецификации. Дополнительно используются пользовательские свойства:

| Свойство | Значение |
|---|---|
| `SPEC_Section` | Раздел: `Documentation`, `Complexes`, `AssemblyUnits`, `Parts`, `StandardProducts`, `OtherProducts`, `Materials`, `Kits` или id пользовательского раздела |
| `SPEC_Format` | Формат |
| `SPEC_Unit` | Единица измерения |
| `SPEC_Group` | Однородная группа (стандартные и прочие изделия) |
| `SPEC_SortName` | Наименование изделия для сортировки («Болт») |
| `SPEC_StandardNumber` | Обозначение стандарта («ГОСТ 7798-70») |
| `SPEC_Parameters` | Основные параметры («М12х60») |
| `SPEC_MaterialKind` | Вид материала: `FerrousMetals`, `MagneticMetals`, `NonFerrousMetals`, `CablesWires`, `Plastics`, `PaperTextile`, `Wood`, `RubberLeather`, `MineralCeramicGlass`, `PaintsChemicals`, `Other` |

Если `SPEC_SortName`, `SPEC_StandardNumber`, `SPEC_Parameters` не заполнены, они берутся из разбора наименования («Болт М12х60 ГОСТ 7798-70»).
